The developer tools

Inside the window

⌥⌘I, or “Inspect Element” on right-click. The panel sits over the bottom of the page without resizing it, follows the tab you're looking at, and detaches into a window of its own.

Elements

The document tree, kept up to date; search by selector, text, tag or attribute; the breadcrumb. Hovering highlights margin, border, padding and content. The arrow keys walk the tree, ← goes up to the parent without collapsing anything.

Editing in place

A double-click opens the line in color: the whole node if it's small, its opening tag if it's large. ⌘S saves, Escape gives up — and the element is adjusted in place, not recreated.

Styles, computed, box, listeners

Rules as they're written — including those from a style sheet on another site —, computed values, the box, and the listeners of the element and its ancestors with their file and line.

Console

What the page writes, its errors with their stack, objects you can expand, console.table as a table, $0 for the selected element, and a line to evaluate in the page — or in a frame.

Sources

Scripts and style sheets, formatted and colored, across the whole file: a 3.6 MB script reads in full, with search and line wrapping.

Network

Each resource, its status, its size, its time and its timeline; method and headers for fetch and XMLHttpRequest; reload without the cache.

Storage

Cookies — HttpOnly included —, which can be written and edited; local and session storage; IndexedDB databases and their tables; Cache Storage and service workers.

What comes before opening

The last three hundred messages, the last three hundred requests and all listeners are kept before you open the panel — less than a microsecond per listener.

Frames, even from another site

An <iframe> expands in the tree; an element picked in a frame takes the console there.

Your site, live

You write your site in your editor, you watch it in Wuji — and it reloads on every save, without a development server.

From disk

file:///Users/…/index.html typed in the bar, or the path your editor copies — /Users/…, ~/…. The Finder's “Open With” offers Wuji for an HTML page.

On every save

The page, its style sheet, its script, an image: when a project file changes, its tabs reload — once per save, without injecting anything into the page or opening a port.

The project folder

A page in pages/naviguer/ finds its style sheet in ../../styles/: Wuji opens access to the project — the folder containing .git, .vscode or package.json —, never to the home folder or the rest of the disk.

Links as on a server

A link to a folder opens its index.html. What isn't the site — .git, .DS_Store, the editor's working files — reloads nothing.

Device mode

A phone inside the window

iPhone 16 Pro Max, 16 and SE, Pixel 9, Galaxy S24, iPad mini, iPad and iPad Pro 13, or a custom size, rotatable. The page is laid out at the device's width and gets its browser's identity.

The mouse becomes a finger

maxTouchPoints, ontouchstart, the touchstart and touchend events, a round cursor. A screen larger than the available space is scaled down, and the panel says by how much.

User scripts

Install

From a .user.js address — the Greasemonkey convention — or from a page that turns out to be a script. Its scope is shown before you accept, every site counted; updating happens on request, and asks again if it targets more sites or powers. A script never runs in Wuji's own pages.

Writing

A colored editor, in Settings › Scripts, to write or touch them up.

Once per document

A script runs once, and follows page changes itself — Tampermonkey's contract. On YouTube, which changes video without reloading, it is set when arriving on the page it targets, never twice.

Nothing when nothing runs

With no active script, nothing is set in pages. The icon stays in the bar, faded when nothing runs here.

What the tools can't do

  • No breakpoints, no stepping. That's a debugger's job, which WebKit doesn't lend to an app.
  • In device mode, @media (pointer: coarse) doesn't change: WebKit takes it from the hardware.
  • A style sheet a site refuses even to the page's own request, and that the archive didn't keep, stays unreadable — and it says so.
